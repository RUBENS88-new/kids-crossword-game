# kids-crossword-game (MVP)

MVP веб-приложения для детских кроссвордов на русском языке.

## 1) Что это

Приложение состоит из двух частей:
- **Публичная часть для игрока**: список опубликованных кроссвордов, экран игры, экран завершения, рейтинг.
- **Админ-часть**: вход по логину/паролю, загрузка ZIP-архивов кроссвордов и тем, публикация/снятие с публикации, удаление и привязка темы к кроссворду.

---

## 2) Требования

Минимально нужно:
- **Python 3.9+** (рекомендуется 3.10+).
- Современный браузер (Chrome / Edge / Firefox / Safari).

Проверить Python:

```bash
python --version
```

Если команда `python` не работает, попробуйте:

```bash
python3 --version
```

## 4) Как пользоваться приложением

## Игрок

1. На главной странице выберите опубликованный кроссворд.
2. Нажмите **«Играть»**.
3. Выбирайте слово кликом по сетке (слева).
4. Справа отвечайте **кнопками букв** (без клавиатуры).
5. Используйте подсказки в пределах лимита:
   - **Описание**
   - **Показать букву**
   - **Только буквы слова**
6. После завершения введите имя и отправьте результат в рейтинг.

## Администратор

1. На главной нажмите **«Вход для администратора»**
   (или откройте `http://localhost:8000/#admin`).
2. Введите:
   - логин: `admin`
   - пароль: `kids123`
3. В админке можно:
   - загрузить ZIP-кроссворд,
   - загрузить ZIP-тему,
   - привязать тему к кроссворду,
   - опубликовать/снять с публикации,
   - удалить кроссворд или тему.

## 5) Форматы загрузки

## ZIP кроссворда

Структура:

```text
<archive>.zip
├─ crossword.json
└─ images/
   ├─ dog.png
   ├─ cat.png
   └─ ...
```

Минимум в `crossword.json`:
- `id`, `title`, `gridWidth`, `gridHeight`, `hintLimit`, `grid`, `words`.

Для каждого слова обязательны:
- `id`, `direction`, `row`, `col`, `answer`, `question`, `image`, `descriptionHint`, `fact`, `extraLetters`.

## ZIP темы

Структура:

```text
<archive>.zip
├─ skin.json
├─ images/
│  └─ ...
└─ icons/
   └─ ...
```

Обязательные блоки в `skin.json`:
- `id`, `title`, `colors`, `background`, `crosswordBoard`, `sidePanel`, `character`, `buttons`, `reward`.

---

## 6) Какие проверки выполняются при загрузке

### Для кроссворда
- читаемость `crossword.json`;
- обязательные поля;
- соответствие размеров сетки `gridWidth/gridHeight`;
- ответы только русскими буквами;
- совпадение слов с буквами в сетке;
- координаты слов в пределах сетки;
- наличие всех указанных изображений в архиве;
- целочисленный `hintLimit`.

### Для темы
- читаемость `skin.json`;
- обязательные поля `id` и `title` + обязательные блоки;
- корректность цветов (`#RRGGBB`);
- наличие всех обязательных изображений/иконок в архиве.

Если что-то не так, в админке вернётся понятная ошибка (например: «Не найден файл ...», «Координаты слова выходят за границы сетки»).

---

## 7) Где хранятся данные

Во время работы автоматически создаётся папка `data/`:
- `data/app.db` — SQLite база (кроссворды, темы, рейтинг);
- `data/uploads/crosswords/...` — распакованные архивы кроссвордов;
- `data/uploads/skins/...` — распакованные архивы тем.

Эта папка не коммитится в git (`.gitignore`).
